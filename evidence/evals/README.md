# evidence/evals/ — E10.3

The eval harness's golden sets, its **latest** scorecard, and **history**.

- **Golden sets + harness:** [`../../evals/`](../../evals/) — `golden_sql.json` (32
  text-to-SQL cases), `scenarios.json` (8 full-estimate scenarios), `faults.py` (30
  fault-injection cases), `output_guard.py` (un-sourced-number guard).
- **Latest scorecard:** [`../../evals/SCORECARD.md`](../../evals/SCORECARD.md) —
  regenerated by `python evals/runner.py` on every push; CI fails if it drifts.
- **History:** [`history/`](history/) — a dated copy of the scorecard is written by
  `python evidence/scorecard.py` each run. The full history is also the git log of
  `evals/SCORECARD.md`.

The scorecard feeds the **Reliability** dimension of
[`../SCORECARD.md`](../SCORECARD.md).
