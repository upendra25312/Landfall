## Reading this

`unrecognised` = no source profile matched; the file is logged and skipped. `rejected` = a profile matched but a required column is absent on every row; nothing loads. `ok` = the rows loaded, and the confidence + findings above are what the pre-sales team and the client see — the estimate proceeds at a stated, lowered confidence with an explicit "ask the client for X" list.
