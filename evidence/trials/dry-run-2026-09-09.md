# Comprehension trial — apparatus dry run (2026-09-09)

**Not a trial result.** A self-administered pass to check the comprehension task
set is answerable from the docs alone, well-posed, and objectively scorable
before spending three people's time. Run by the author, so it says nothing about
whether a *new* consultant can do it — that is what the real trial (`protocol.md`
Trial A) is for.

**Materials checked:** `docs/how-landfall-works.html` v1.0, `docs/operating-sop.html`.

## Task-by-task

### Task 1 — explain the pipeline
- **Answerable from the docs?** Yes. `how-landfall-works.html` §2 gives the five
  stages with a diagram; §1 gives "agent orchestrates, tools compute"; §6 lists
  the architect-owned decisions. A reader who read §1, §2, §6 can hit every
  point on the pass line.
- **Well-posed?** Yes.
- **Scorable?** Yes — the pass line is a concrete checklist.

### Task 2 — run an estimate and trace a number
- **Answerable?** Partly doc, partly system. The *method* (find the F-id → open
  the calculation appendix → read formula/inputs/confidence/band) is in §4 and
  the worked example §7. The *doing* needs a live deployment with data loaded —
  so this task has an environment dependency the facilitator must satisfy
  (engagement pre-loaded with the sample estate).
- **Numbers verified:** ran `evals/pipeline.py` (scenario SC1). run-rate
  **$113,911/mo** = 81,439 + 16,184 + 16,287. Matches the doc and the answer key
  to the dollar.
- **Trap found + fixed:** the first draft of the answer key said the cost figure
  is "Medium" confidence. It is **Low** — `assemble.py` caps any pre-discovery
  cost figure at Low by design (`_worst(dq_conf, "Low")`). Added a callout to
  §5 of the doc and corrected the answer key so "Low" is the full-credit answer.
- **Well-posed?** Yes, once the facilitator setup step (pre-loaded engagement) is
  explicit — it now is, in `protocol.md`.

### Task 3 — interpret a Low-confidence answer
- **Answerable from the docs?** Yes. §5 (confidence model + the "not a failure of
  Landfall" framing + "data gaps are client-asks") and §6 (architect owns any
  Low figure) cover every point on the pass line.
- **Well-posed?** Yes — it gives a concrete scenario (62% no utilisation history)
  rather than asking in the abstract.
- **Scorable?** Yes.
