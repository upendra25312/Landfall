0How to complete this

  • Answer inline. “Unknown” is a valid answer — it tells us where to place a discovery activity or an assumption.
  • Priority tags: MUST blocks the estimate · SHOULD materially changes it · NICE refines it.
  • Attach the data pack in §1 to the agreed Data Lake container. Spreadsheet exports are fine; we do not need tooling installed.
  • One named client owner per section, please, so we can follow up quickly.
